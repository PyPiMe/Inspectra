Shell
  • 一行一个 key=value；多值可在行内附 threshold=>90 / warn=>80 / unit=%。
  • 纯信息类加 # DISPLAY: true（仅展示、不判定）。
  • 异常行用 ERROR: 前缀；保存前自动 bash -n 校验。
PromQL
  • 头部元数据：# NAME / # MODE: instant|range / # WINDOW / # STEP / # THRESHOLD / # WARN / # UNIT / # DISPLAY。
  • 占位符：$instance（实例匹配器）、$guest（PVE 虚拟机）。
  • 多指标阈值：label_replace(..., "threshold", ">90", ...) 让每条 series 自带阈值。
  • 结果按 item=<名> 标签展示；MODE=range 取区间最后一个值判定。
